Instructions Piratage

Utilisation du terminal de piratage de données.

1 Présentation du matériel

Le terminal :

Il permet d'écrire et de lire des informations sur une disquette de données. Sur mission, vous serez amené à en trouver ; il vous faudra les hacker pour pouvoir accéder aux diverses informations de la disquette.

2 Entrée des données

Pour entrer des données, il suffit d'aller dans l'onglet « Donnée », copier son message, puis entrer le mot de passe souhaité et cliquer sur « Verrouiller ».

Une fois le terminal verrouillé, cette interface apparaît.

3 Hacking

Pour lancer le hacking, il faut aller dans l'onglet « Hack » puis cliquer sur « Start Hack ».

Une fois dans la console, il suffit de recopier les mots surlignés.

4 Lecture des données

Ça y est, vous avez accès aux données, félicitations !
