1 Bombe MK1

Il faut couper le fil correspondant à la disposition :

  • S'il y a plusieurs possibilités, c'est le plus haut qui l'emporte (ex. 2 fils bleus, dernier fil noir → 2ᵉ fil).
  • S'il y a plus d'un fil bleu, couper le 2ᵉ fil.
  • Si le dernier fil est noir, couper le 3ᵉ fil.
  • Si le premier fil est jaune, couper le 4ᵉ fil.
  • Si le premier et le dernier fil sont rouges, couper le 2ᵉ fil.
  • Si aucun des cas ci-dessus ne s'applique, il s'agit du 4ᵉ fil.

2 Bombe MK2

Il faut entrer le code correspondant à la bombe (après avoir coupé le fil) :

  • Bombe large et à gaz MK2 : 10100011 (si le code n'apparaît pas, sélectionner l'avant-dernier code)
  • Bombe moyenne MK2 : 10000000
  • Bombe petite MK2 : 01010101
  • Bombe entraînement MK2 : 00000100
